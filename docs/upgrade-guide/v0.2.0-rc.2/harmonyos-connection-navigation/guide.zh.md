# 鸿蒙连接设置使用原生导航

[English](guide.md) | 中文

## 变更

连接页面使用鸿蒙原生导航和返回动画，跟随系统浅深色主题并保持纵向。WebView 在系统旋转锁关闭时允许纵向与横向旋转，其背景跟随系统主题，并扩展到透明系统栏下。传输断线保留当前 WebView，使用 [SDK 恢复机制](../harmonyos-broker-sdk-recovery/guide.zh.md)。标题栏右侧为**保存**；**测试连接**与仅编辑时显示的**删除连接**并排位于底部。本地和远程设置不再提供模式切换，请在添加连接时选择模式。

新建 broker 服务地址为空，不提供示例域名。远程设置先显示已登录服务与账号，再显示所选 broker，两项均可**修改**。取消服务修改时恢复原身份；选择其他 broker 时清除原连接密码。已保存的服务地址和凭据保留。

## 迁移

1. 使用标题栏的**保存**代替**完成添加**。使用其他模式时另建连接。
2. 新建远程连接时，填写自己的 HTTPS broker 服务地址并登录，证书仍必须受系统信任。
3. 通过服务右侧的**修改**更改登录信息，或通过 broker 右侧的**修改**重新选择；保存前输入新 broker 的连接密码。

当前连接流程由 [App 说明](../../../../ohos/app/README.zh.md)维护。此次变更不修改 App 偏好版本、DSH Session 日志或 SQLite 数据。
